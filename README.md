# 🇵🇭 ReadyPH – Disaster Preparedness Website

## About the Project
ReadyPH is a disaster preparedness website designed to help Filipino households prepare for natural disasters and emergencies. It provides useful information and tools to help families organize their emergency supplies and become more prepared before disasters happen.

## Project Purpose
The purpose of ReadyPH is to promote disaster awareness and encourage Filipino families to prepare essential emergency supplies. Through this website, users can make better preparations and become more informed about disaster readiness.

## Features
- **Emergency Checklist** – Helps users identify and organize essential emergency supplies.
- **Supply Calculator** – Helps households estimate the supplies they may need.
- **User-Friendly Interface** – Provides a simple and accessible website experience.

## Technologies Used
- HTML – For the structure of the website.
- CSS – For the design and layout.
- JavaScript – For website functionality and calculations.

## Project Files
| File | Description |
|---|---|
| `index.html` | Main structure of the website |
| `style.css` | Website design and styling |

## How to Use
1. Open the ReadyPH website.
2. Explore the disaster preparedness information.
3. Use the emergency checklist to organize supplies.
4. Use the supply calculator to estimate household needs.

## Project Goal
ReadyPH aims to encourage disaster preparedness among Filipino households by making emergency planning easier, more accessible, and more organized.
