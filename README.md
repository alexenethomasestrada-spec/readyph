# ReadyPH
A simple website that shows how prepared a household is for a typhoon, tsunami, or earthquake.

- `index.html` the page structure (HTML)
- `style.css` the look and layout (CSS)
- `script.js` the behavior: checklists, percentage, supply calculator, hotlines (JavaScript)

No installation needed. Open `index.html` in a browser.

## Put it online with GitHub Pages
1. Create a new public repository on github.com.
2. Click **Add file**, then **Upload files**, drag these files in, and click **Commit changes**.
3. Go to **Settings**, then **Pages**. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
4. After a minute or two your site is at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Check every emergency number on the agency's official website before relying on it.
